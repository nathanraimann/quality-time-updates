# Quality Time – Updates

Hier stehen die offiziellen signierten Update-Dateien für Quality Time bereit.

[Neueste Version herunterladen](https://github.com/nathanraimann/quality-time-updates/releases/latest)

## Installieren

Die vollständige Update-APK über die bereits eingerichtete App installieren. Die App vorher **nicht deinstallieren** und keine App-Daten löschen. Bestehende Termine, Kalenderzuordnungen und Einstellungen bleiben erhalten. Zwischenupdates sind nicht erforderlich.

## Automatische Updates

Ab Version 0.10.0 prüft Quality Time beim Öffnen auf neue Versionen. Unter **Mehr → App-Updates** kann die Prüfung ein- oder ausgeschaltet werden. Android verlangt gegebenenfalls einmalig **Installation durch Quality Time erlauben** und kann eine Installationsbestätigung anzeigen. Ein laufender Desktop oder Laptop wird für den Download nicht benötigt.

## Private Einrichtung

Die allgemeinen Update-APKs enthalten keine persönlichen Familienzugänge und keine Kalenderdaten. Bereits eingerichtete Apps behalten ihre lokal gespeicherten Zugänge. Neue Geräte benötigen weiterhin eine persönliche Einrichtung. Persönliche Einrichtungsdateien gehören nicht in dieses öffentliche Downloadprojekt.

Die App prüft Paketname, Version, SHA-256 und den bisherigen Signierer vor einer Installation.
